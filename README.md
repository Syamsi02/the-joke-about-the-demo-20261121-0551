(Node 22, stdlib only) to `/output/entry.txt`.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out npx tsx main.ts
```

(or run `main.ts` with any TypeScript runner for Node 22; it only uses
`node:fs` and `node:path`.)
